# copick-helix

Fast, data-driven polarity, lattice and in-plane orientation of traced filaments (microtubules, actin,
intermediate filaments) in cryo-electron tomograms, for copick projects. No subtomogram refinement: the
filament's own helical Fourier signal, restricted to where its structure puts signal, measured only where the tilt
series sampled it.

See `PLAN.md` for the design and status.
